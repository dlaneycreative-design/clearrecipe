페루 · 메인 · 쉬움

전통 로모 살타도

페루가 사랑하는 볶음 요리, 겉을 익힌 소고기와 양파, 토마토를 감자튀김과 버무려 밥 위에 냅니다.

준비 15 분조리 15 분인분 4
#Peruvian#Mains

60초에 끝내는 레시피

로모 살타도, 5가지 아이디어로

  1. 연기가 날 만큼 뜨거운 웍이 상징적인 훈연 그을음을 만듭니다.
  2. 소고기를 빽빽하게 넣으면 찌게 되니 그러지 마세요.
  3. 감자튀김은 바삭함을 유지하도록 마지막에 넣습니다.
  4. 아히 아마리요는 과일 같은 매운맛을 더합니다. 라틴 식재료점에서 구하세요.
  5. 식초는 산뜻함을 유지하도록 마지막에 넣습니다.

필요한 재료

재료

  • 설로인 길게 썬 것 680g
  • 감자 튀김 모양으로 썬 것 3개
  • 적양파 쐐기 모양으로 썬 것 1개
  • 토마토 쐐기 모양으로 썬 것 3개
  • 간장 2큰술
  • 레드와인 식초 2큰술
  • 아히 아마리요 페이스트 1큰술
  • 마늘 다진 것 3쪽
  • 기름 60ml
  • 소금과 후추
  • 익힌 밥 4그릇
  • 다진 고수

만드는 법

조리법

  1. 감자를 바삭하게 튀겨 물을 빼고 소금을 뿌립니다.
  2. 연기가 날 만큼 뜨거운 웍에 소고기를 나누어 겉을 익혀 따로 둡니다.
  3. 양파와 마늘을 2분간 볶습니다.
  4. 토마토, 간장, 식초, 아히 아마리요를 넣습니다.
  5. 소고기와 감자튀김을 다시 넣고 전부 1분간 버무립니다.
  6. 고수를 올려 밥 위에 냅니다.
플랭크 스테이크도 잘 어울리고 설로인보다 저렴한 경우가 많습니다.
